# 会话记忆总结优化:以当前对话为主、旧版仅供连贯参考 Spec

> 决策(用户已确认):旧版会话记忆**仅作连贯参考、不重复输出**;内容源保持**基于章节记忆(现状)**。

## Why
生成会话记忆时,旧版会话记忆摘要(同 chatId 上一次生成的)被要求"在旧版基础上合并全部章节后重新输出",导致旧总结内容被重复合并进新会话记忆,而不是以当前对话内容为主。

目标(按用户确认):**以当前会话内容为主要总结依据;旧版会话记忆仅作连贯性参考(了解上一版结构与基调),不在结果中重复输出其内容**。

## 现状调查(回答:现在会话记忆是怎么总结的)
- **内容源**:`buildSessionPrompt` 的输入是**当前对话的全部章节记忆摘要**(`chatChapters` 的 `summary`)+ 世界核心记忆 + 旧版会话记忆(现状)。**不是原始对话消息**。章节记忆是对话内容的归档压缩(增量生成、带 prevSummary 连贯),所有有效章节连续覆盖当前对话全部消息。
- **前置依赖**:`generateSessionMemory` 在无章节记忆时直接返回失败(先生成章节再生成会话记忆)——即**有会话记忆必有完整章节覆盖**。
- **重复生成路径**:旧 session 记忆软失效(invalidated)并插入新记录,列表按 chatId 去重取最新。

## 关于"缓存命中率"与"上下文连贯性"的说明
- **缓存**:会话记忆总结是手动触发的一次性后台生成调用,不属于聊天请求稳定前缀;本次改动不改变任何实际聊天请求内容,与聊天缓存命中率无关。
- **连贯性**:章节记忆生成时已通过 `prevSummary` 保持剧情连贯并连续覆盖;旧版会话记忆保留为"连贯性参考"输入(不以正文形式写入新摘要),进一步保证新摘要的框架、基调与上一版衔接,且不会重复。

## What Changes
- `MemoryService.buildSessionPrompt`:
  - 保留 `oldSessionSummary` 参数,但用户输入段标注为**【旧版会话记忆(仅作背景与连贯性参考,不要重复输出其内容)】**。
  - 系统提示词改为:主体 = 当前对话的全部章节记忆;旧版会话记忆仅用于了解上一版结构与基调以保持连贯;严禁把旧版内容重复写进新摘要;若旧版与当前章节冲突,以当前章节为准。
  - 删除原"在其基础上合并全部章节后重新输出"的指令。
- `MemoryService.generateSessionMemory`:`oldSession.summary` 仍作为 `oldSessionSummary` 传入(供连贯参考),其余(软失效旧记录、插入新记录、实体索引)不变;更新注释说明"旧版仅作连贯参考,主体为当前章节"。
- 世界核心记忆仍作为辅助上下文输入(世界级稳定事实,不属于会话记忆)。
- 调用方 `MemoryManagementViewModel.generateSessionMemory` 无需改动。

## Impact
- Affected specs: 会话记忆生成(v46 入口级压缩摘要)
- Affected code:
  - `entry/src/main/ets/services/MemoryService.ets`(`generateSessionMemory` L1228、`buildSessionPrompt` L1352)

## ADDED Requirements
### Requirement: 会话记忆总结以当前对话为主、旧版仅作连贯参考
系统 SHALL 在生成/重复生成会话记忆时,以当前对话(chatId 过滤)的全部有效章节记忆为摘要主体;旧版会话记忆可作为输入仅供连贯性参考,但不得要求模型重复输出其内容。

#### Scenario: 成功场景 - 重复生成会话记忆
- **WHEN** 用户在记忆管理页对同一会话再次点击"生成会话记忆"
- **THEN** 旧版会话记忆被软失效并替换为新记录;新摘要主体来自当前对话的全部章节记忆,旧版内容不重复出现,仅在结构/基调上保持与旧版衔接

## MODIFIED Requirements
### Requirement: 旧 session 记忆清理(v46 既有)
系统 SHALL 在生成新会话记忆时软失效同 chatId 旧 session 记忆再插入新记录,避免列表重复;保持不变。
- 旧记录软失效(不变)、新记录插入并携带实体索引 detail 与实体名 keywordsJson(不变)

## REMOVED Requirements
### Requirement: 旧版会话记忆作为"合并重写"的正文输入(v46)
**Reason**: "在旧版基础上合并全部章节重新输出"导致旧内容被重复总结进新摘要。
**Migration**: 旧版会话记忆降级为连贯性参考输入,仅参与提示词上下文,不要求输出其内容;历史内容由章节记忆完整覆盖保存。
